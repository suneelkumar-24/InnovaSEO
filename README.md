# 🎯 Niche Hunter

**Niche Hunter** is an AI-powered Market Research & Niche Discovery platform built with Next.js 15, Tailwind CSS, Google Gemini 2.0 Flash, and Anthropic Claude 3.7 Sonnet.

---

## 🚀 Quick Setup Guide

### 1. Open in Antigravity
Open this standalone directory in **Antigravity**:
```
D:\niche-hunter
```

### 2. Configure Your AI Keys
Open `.env.local` in this folder and add your API keys:
```env
# Free Gemini API Key from https://aistudio.google.com
GEMINI_API_KEY=your_gemini_api_key_here

# (Optional) Anthropic Claude API Key from https://console.anthropic.com
ANTHROPIC_API_KEY=your_claude_api_key_here
```

### 3. Install Dependencies & Run
In the terminal of `d:\niche-hunter`:
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
